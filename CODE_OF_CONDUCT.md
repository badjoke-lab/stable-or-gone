# Code of Conduct

Stable or Gone is a source-backed historical registry. Keep reports factual, specific, and evidence-based.

## Expected behavior

- Be factual.
- Stay source-based.
- Discuss records, sources, and methodology rather than attacking people.
- Use GitHub Issues for public, source-backed registry reports.
- Use the contact form for non-public messages.

## Unacceptable behavior

- Harassment, threats, or personal attacks.
- Posting private or sensitive information.
- Token promotion, spam, or marketing.
- Investment advice requests.
- Issuer, exchange, wallet, or redemption support requests.
- Repeated unsourced claims after sources have been requested.

Maintainers may edit, close, hide, or remove issues and comments that do not follow these rules.
