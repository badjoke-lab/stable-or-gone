# Security Policy

Stable or Gone is a static registry site. It does not provide accounts, wallets, exchange services, redemption services, or custody.

## Reporting security issues

Use the contact page for security-related reports:

https://sog.badjoke-lab.com/contact/

Do not open a public GitHub Issue for a sensitive security report.

## Scope

In scope:

- exposed secrets in this repository
- unsafe site behavior affecting visitors
- broken security-sensitive links or misleading support paths

Out of scope:

- issuer, exchange, wallet, or redemption support
- market losses
- investment advice
- disputes about stablecoin risk
- automated scanning that creates load or noise
- social engineering
- attempts to access accounts, wallets, private data, or third-party systems

## No bounty program

Stable or Gone does not operate a bug bounty program. Reports are reviewed on a best-effort basis.

## Sensitive information

Do not submit private keys, seed phrases, passwords, wallet credentials, exchange account details, bank information, identification documents, or sensitive personal information.
