# Support

## Purpose

SOG includes a support/donation route from v0.

Support is for maintaining the public registry, improving data quality, adding sources, and keeping the project independent.

## Placement

Support should appear in:

- header utility link
- footer
- `/support/`
- about page support section

Support should not be the main homepage CTA.

## Good language

Use:

```txt
Support SOG
Support this registry
Help keep this project independent
Support source-backed stablecoin records
```

## Avoid

Do not use language that implies rating, safety certification, or investment protection.

Avoid:

```txt
Fund our ratings
Keep stablecoins safe
Donate for risk scores
Support our safety ranking
```

## Support page draft

```txt
Stable or Gone is an independent stablecoin registry focused on issuers, reserves, depeg events, redemption access, lifecycle changes, and source-backed evidence.

Your support helps keep the registry updated and independent.

SOG does not sell stablecoin ratings, recommendations, or investment advice.
```
