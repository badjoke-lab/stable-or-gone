# Reporting and Contact

## Purpose

SOG uses two reporting routes:

1. Google Form for contact, private/simple reports, and non-technical corrections.
2. GitHub Issues for public, source-backed reports and corrections.

## Contact route

Contact is handled through Google Form.

Use Google Form for:

- general contact
- private correction report
- simple broken link report
- missing stablecoin report
- missing issuer report
- missing depeg event report
- missing reserve / attestation source
- questions that should not be public

## Public report route

GitHub Issues are used for public, source-backed corrections.

Use GitHub Issues for:

- corrections with source URLs
- missing stablecoin proposals
- missing depeg/event evidence
- broken public source links
- reserve report additions
- issuer information corrections

## Google Form fields

Suggested fields:

```txt
Report type
Relevant stablecoin / issuer
Page URL
Message
Source URL(s)
Can this report be public? yes/no
Contact email optional
```

Report type options:

```txt
Correction
Missing stablecoin
Missing depeg event
Missing issuer information
Reserve / attestation source
Redemption / wind-down source
Broken link
General contact
```

## Public issue guidance

Public issue text should ask for:

```txt
Stablecoin or issuer name
Affected SOG page URL
What should be corrected or added
Source URL(s)
Why the source supports the correction
Whether the report concerns status, depeg event, reserve, redemption, issuer, or evidence
```

## Privacy note

Google Form should be the route for reports that should not be public.

GitHub Issues are public by default.

## Correction language

Preferred UI labels:

- Contact
- Submit correction
- Report this entry
- Open GitHub issue

Detail pages should use:

```txt
Report this entry
```

Registry pages and footer can use:

```txt
Submit correction
```
