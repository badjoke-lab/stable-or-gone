## Visual rules represented by the approved direction

- off-white or lightly warm paper background;
- dark ink;
- muted dark-red accent used sparingly;
- thin rules instead of repeated cards;
- square or nearly square corners;
- no decorative shadows;
- editorial serif headings with readable sans-serif body text;
- monospace IDs and dates;
- information hierarchy created by type, rules, spacing, and columns;
- no dashboard composition;
- no KPI-card row;
- no oversized marketing hero;
- no blue-purple glow;
- no new logo.

## Logo rule

The reference direction does not authorize a replacement logo. Production must reuse:

## Interpretation rule

The four-page reference controls composition and visual language, not canonical facts. Exact record values, counts, evidence, and dates must come from canonical data or approved editorial copy.
