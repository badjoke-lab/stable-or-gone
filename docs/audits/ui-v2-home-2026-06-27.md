## Implemented composition

The Home page now uses the approved v2 hierarchy:

1. modern registry hero;
2. cross-registry search;
3. four canonical metric cards;
4. four primary registry entry cards;
5. three real dated guide cards;
6. explicitly selected stablecoin records;
7. approved support banner;
8. shared v2 footer.

## Search scope

The static client-side search index is built during site generation from:

```text
92 stablecoin records
86 organization records
150 event records
```

Search results link only to existing route families:

```text
/stablecoin/[slug]/
/issuer/[slug]/
/event/[id]/
```

The search uses no external API or runtime network fetch. The form retains a no-JavaScript fallback to `/stablecoins/?q=...`.

Search interaction includes:

- progressive results;
- polite result announcements;
- escaped result markup;
- single-result direct navigation on submit;
- Escape close and focus return;
- click-outside close;
- popular-query controls for USDT, USDC, DAI, and UST.

## Canonical metrics

The Home page renders dynamic counts from the runtime registry and evidence source summary:

```text
stablecoins.length
organizations.length
events.length
evidenceSummary.source_identities
```

No count is copied from the mock or hard-coded into page markup.

## Selected-record rule

The old raw-order expression `stablecoins.slice(0, 10)` was removed.

The replacement rule is an explicit ordered slug list:

```text
usdt
usdc
dai
ust
busd
frax
tusd
fdusd
pyusd
usdd
```

The same fields are present in the desktop table and compact cards:

- identity;
- symbol;
- reference target;
- model;
- lifecycle;
- issuance;
- primary organization.

## Shared components

The page uses:

```text
PageHero
MetricCard
SupportBanner
TickerBadge
```

Page-specific styling is isolated in `src/styles/home-v2.css`. The shared visually-hidden utility is loaded through `BaseLayout.astro`.

## Mock-only exclusions

The implementation does not add:

- live price;
- market capitalization;
- circulating supply;
- holder or transfer counts;
- market charts;
- monthly growth deltas;
- saved views;
- watchlists;
- accounts or follow controls;
- recent-history features;
- unsupported badges or scores.

## Validation

`scripts/validate-ui-v2-home.mjs` verifies:

- approved reference presence;
- shared component use;
- hero statement;
- search coverage and route families;
- dynamic canonical counts;
- real primary destinations and guides;
- explicit selected-record slug order;
- removal of raw array slicing;
- desktop and compact selected-record representations;
- search announcement, Escape, and escaping behavior;
- responsive Home style markers;
- mock-only feature absence;
- external runtime-fetch absence.

The validator runs in both `npm run build` and `npm run build:site`.
