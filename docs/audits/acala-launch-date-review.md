# Acala aUSD launch-date review

The canonical Acala aUSD / aSEED record now uses `2022-02-10`, matching the existing high-confidence launch event sourced from Acala's official launch announcement.

The dated launch-context events for crvUSD (`2023-05-01`) and USDe (`2024-02-01`) remain low-confidence review context and were not promoted into canonical launch dates.
