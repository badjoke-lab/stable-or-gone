# RLUSD and EURC launch-date review

- RLUSD: `2024-12-17`, based on Ripple’s official announcement that global exchange availability would begin on that date.
- EURC / Euro Coin / EUROC: `2022-06-30`, based on Circle’s official announcement of availability and Ethereum launch on that date.

The EURC date represents the continuous Circle euro-stablecoin identity; the later EURC name and symbol do not create a separate canonical asset.
