# SOG CYA Dark Port Contract

SOG uses the actual Crypto Yield Archive implementation as its public UI structural source.

## Required structure

- compact masthead and horizontally scrollable primary navigation;
- editorial introduction beside a 2 x 2 registry facts grid;
- archive scope strip;
- numbered two-column directory;
- full canonical registry table as the homepage's primary content;
- square, flat, rule-led surfaces with no shadows or filled status pills;
- mobile tables represented as compact labelled records without hiding evidence content.

## Dark adaptation boundary

SOG may change colors, copy, routes, and record fields. It must not replace the CYA information architecture with rounded cards, SaaS panels, dashboard sidebars, or oversized mobile cards.

## Enforcement

The single public stylesheet, rendered-route audit, screenshot audit, text contrast audit, mobile evidence preservation checks, active-link state, and flat status-label contract are blocking gates.
