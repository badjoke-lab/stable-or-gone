# SOG AI-era Registry Specification

Status: planned / mandatory future-work reference

## Goal
SOG must preserve the lifecycle and aftermath of stable assets, not merely classify current status or list depegs.

## Required work
- Preserve current classification and provenance integrity rules.
- Track evidence-backed lifecycle: launch -> stress/depeg/regulatory action -> issuer/protocol intervention -> redemption/recovery/compensation -> migration/discontinuation -> current/final state.
- Keep canonical enum values stable unless a separately reviewed schema change is required.
- Expose provenance, uncertainty, last verification and evidence scope prominently.
- Provide deterministic per-asset machine-readable JSON derived from canonical records.
- Strengthen structured filtering by issuer/mechanism/status/regulatory/depeg/outcome dimensions supported by canonical data.
- Extend the existing comparison/change product rather than creating a parallel AI comparison system.
- Add Stats for status composition, depeg/recovery outcomes, regulation/migration, timelines and data quality.
- Automated discovery may stage signals but cannot directly reclassify an asset.

## Non-goals
No price prediction, investment ranking, AI-generated canonical classification, prompt buttons or chatbot-first product.

## Mandatory reference
All future SOG classification, comparison, monitoring, data-growth, machine-readable and Stats work must consult this file alongside existing specs; stricter existing integrity rules prevail.
